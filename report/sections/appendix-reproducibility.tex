\section{Reproducing the Numbers}
\label{app:reproducibility}

Every measured value in this report is a LaTeX macro generated from a saved notebook output, the same cells that
the repository's README cites. Values computed from them, such as the ratios to the paper's timings, are generated
the same way. The other numbers in the text are the paper's own figures, cited where they appear, and the settings
of the experiments ($N$, $t$, the 100~KB document). To reproduce the numbers from scratch:
\begin{enumerate}
  \item Create the environment with \texttt{uv sync} in the repository root.
  \item Run the unit tests with \texttt{.venv/bin/python -m unittest discover -s tests}.
  \item Run all notebooks with \texttt{.venv/bin/python scripts/run\_notebooks.py}, on an otherwise idle machine
        with at least three logical CPUs. On the test machine notebook~08 takes the longest by far
        (\cref{tab:notebook-cost}).
  \item Regenerate the report's values with \texttt{.venv/bin/python report/tools/make\_numbers.py}, then rebuild
        the report with \texttt{latexmk} in \texttt{report/}.
  \item Run \texttt{.venv/bin/python report/tools/invert\_commitment.py} to check the commitment finding of
        \cref{sec:findings}.
\end{enumerate}
Timings will differ on another machine. Sizes, counts and pass or fail results will not.

\Cref{tab:provenance} lists every generated value with the notebook cell that printed it. Cell $k$ is the
$k$-th code cell of the notebook.
